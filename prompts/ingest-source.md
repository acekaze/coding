# Ingest Source Prompt

Read `AGENTS.md` first.

Then ingest this source into the wiki:

- target raw source: `raw/sources/<file>`

Requirements:

1. create or update the relevant page in `wiki/sources/`
2. update any relevant pages in `wiki/entities/` and `wiki/concepts/`
3. update `wiki/overview.md` if the source changes the high-level picture
4. update `wiki/index.md`
5. append an entry to `wiki/log.md`
6. report exactly which pages changed and what remains uncertain

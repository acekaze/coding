# Source Handoff Request Template

Copy and send one of these from another device when you need original text from a tracked project.

## Short template

```text
Please create a source handoff for this:

- tracked project:
- source file or topic:
- request type: full copy / excerpt pack / structured source notes
- what I need:
```

## Example 1

```text
Please create a source handoff for this:

- tracked project: 공개과정
- source file or topic: latest public landing page pricing and application section
- request type: excerpt pack
- what I need: exact wording for date, price, and application link
```

## Example 2

```text
Please create a source handoff for this:

- tracked project: 제안서
- source file or topic: Samsung jobcrafting proposal
- request type: excerpt pack
- what I need: the section comparing the 500-person and 100-person versions
```

## Expected result

The host machine should:

- open the original local source if needed
- write the requested evidence into `raw/sources/`
- update the linked wiki page if useful
- commit and push so every device can access the same handoff afterward

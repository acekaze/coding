# 항공권 땡처리 알리미

가고 싶은 지역·기간·목표 가격을 등록해두고, 실제 항공권 가격이 목표 이하로 내려오면 알림을 받는 개인용 웹앱.

- 실제 가격은 RapidAPI의 **Sky Scrapper**(Skyscanner 데이터)로 조회
- 브라우저에서 API를 직접 못 부르므로(CORS), 작은 로컬 서버가 대신 호출
- API 키는 서버에만 보관하고 브라우저에는 노출하지 않음

## 실행 방법

1. 이 폴더로 이동
   ```
   cd flight-deals
   ```

2. `.env.example`을 복사해 `.env`로 만들고, RapidAPI 키를 채우기
   ```
   RAPIDAPI_KEY=여기에_RapidAPI_키
   ```

3. 서버 실행 (Node 18 이상 필요)
   ```
   node server.js
   ```

4. 브라우저에서 열기
   ```
   http://localhost:8787
   ```

## 사용법

- 왼쪽에서 출발지 / 도착지 / 기간 / 목표 가격을 등록
- "지금 가격 확인"을 누르면 실제 최저가를 조회
- 목표가 이하가 되면 카드가 초록으로 바뀌고 알림(토스트 + 브라우저 알림)
- 조건별 최근 가격 추이를 미니 그래프로 표시

## 무료 플랜 주의 (중요)

Sky Scrapper 무료 플랜은 **월 100회** 제한입니다. 아껴 쓰려고 이렇게 설계했습니다.

- 기간 전체가 아니라 **기간 시작일 하루만** 조회 (한 조건당 조회 1회)
- 자동 확인은 켜도 **6시간 간격** (하루 약 4회)
- 기본은 "지금 가격 확인" 버튼 위주로 사용 권장

호출을 더 늘리려면 RapidAPI에서 유료 플랜(PRO 등)으로 올리면 됩니다.

## 파일 구조

- `index.html` / `styles.css` / `app.js` — 화면과 클라이언트 로직
- `server.js` — 로컬 서버 (정적 서빙 + RapidAPI 중계)
- `.env` — API 키 (git에 올라가지 않음)
- `.env.example` — 키 설정 예시

## 보안 메모

- `.env`는 `.gitignore`로 제외되어 저장소에 올라가지 않습니다.
- 채팅 등에 키를 노출한 적이 있다면 RapidAPI에서 키를 재발급(regenerate)하세요.
